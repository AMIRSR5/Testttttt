# طلای سرافراز — فروشگاه آنلاین طلا

## معماری
- Frontend: HTML/CSS/JS خالص، بدون Build، مستقیم روی GitHub Pages قابل آپلود.
- Backend/DB/Auth: Supabase (Free Tier) — PostgreSQL + Auth + RLS.
- اطلاع‌رسانی سفارش به روبیکا: Supabase Edge Function (`supabase/functions/notify-rubika`) — توکن ربات فقط به‌صورت Secret روی سرور، هرگز در Frontend.

## راه‌اندازی (قدم به قدم)

### ۱. ساخت پروژه Supabase
1. در https://supabase.com یک پروژه رایگان بسازید.
2. در SQL Editor محتوای `supabase/migrations/001_init.sql` را اجرا کنید.
3. از Settings → API مقدار `Project URL` و `anon public key` را کپی کنید.
4. این دو مقدار را در `assets/js/supabase-client.js` جایگزین `YOUR-PROJECT` و `YOUR-ANON-PUBLIC-KEY` کنید.

### ۲. فعال‌سازی ورود با گوگل
1. در Supabase → Authentication → Providers → Google را فعال کنید.
2. یک OAuth Client در Google Cloud Console بسازید (رایگان) و Client ID/Secret را وارد کنید.

### ۳. تعیین اولین ادمین
بعد از ثبت‌نام اولین کاربر (خودتان)، در SQL Editor Supabase اجرا کنید:
```sql
update public.profiles set role = 'admin' where id = (select id from auth.users where email = 'ایمیل-شما@example.com');
```

### ۴. اتصال روبیکا (اختیاری)
1. ربات روبیکا خود را بسازید و توکن آن را بگیرید.
2. با نصب Supabase CLI (رایگان):
   ```
   supabase functions deploy notify-rubika
   supabase secrets set RUBIKA_BOT_TOKEN=توکن_ربات_شما
   ```
3. از پنل مدیریت → تنظیمات سایت، اتصال روبیکا را فعال و آیدی چت مقصد را وارد کنید.
4. **نکته مهم:** آدرس دقیق API روبیکا (`botapi.rubika.ir`) در فایل Edge Function بر اساس مستندات عمومی نوشته شده و باید قبل از استفاده واقعی با مستندات رسمی ربات‌ساز روبیکا تطبیق داده شود.

### ۵. دیپلوی روی GitHub Pages
1. محتوای این پوشه را در یک ریپازیتوری GitHub آپلود کنید (بدون نیاز به Build).
2. Settings → Pages → Branch: main → فعال کنید.
3. سایت روی `https://username.github.io/repo-name/` در دسترس خواهد بود.

## چه چیزی ساخته شده

**صفحات کاربر:** خانه، فروشگاه (با فیلتر دسته‌بندی)، جزئیات محصول (گالری، ویدئو، فرمول قیمت شفاف، نقد و بررسی)، سبد خرید، ثبت سفارش (حضوری/غیرحضوری با اعتبارسنجی)، ورود/ثبت‌نام (ایمیل + گوگل)، حساب کاربری (سفارش‌ها، بلیت گردونه)، درباره ما، تماس با ما، لوکیشن (نقشه)، قوانین، نقد و بررسی‌ها، گردونه شانس (چرخش واقعی + وزن احتمال).

**پنل مدیریت:** داشبورد آماری، مدیریت محصولات کامل (تصویر/گالری/ویدئو/فرمول قیمت اختصاصی هر محصول)، دسته‌بندی‌ها، قیمت طلا (دستی یا API + فرمول)، سفارش‌ها (مشاهده و تغییر وضعیت)، نقد و بررسی‌ها (تایید/حذف)، گردونه شانس (جوایز، وزن احتمال، فعال/غیرفعال)، تنظیمات سایت (تماس، اینستاگرام، آدرس، روبیکا).

**دیتابیس:** Migration کامل با RLS برای تفکیک دسترسی User/Admin، Triggerهای خودکار (ساخت پروفایل هنگام ثبت‌نام، اعطای بلیت گردونه بعد از تایید سفارش).

**SEO:** Meta Title/Description/OG روی صفحات اصلی، robots.txt، sitemap.xml (پایه)، Canonical، Lazy Loading تصاویر.

**QR Code:** تولید در صفحه محصول (لینک محصول) و صفحه تماس با ما (اطلاعات فروشگاه).

**بدون قلک/کیف‌پول طلا:** طبق درخواست، هیچ بخشی مربوط به موجودی طلا یا خرید/فروش طلا ساخته نشده است.

## چه چیزی باقی مانده (پیشنهاد قدم بعدی)
- Schema Markup (JSON-LD) برای محصولات — برای SEO محصول در گوگل.
- تولید خودکار sitemap.xml شامل تمام محصولات (نیاز به یک اسکریپت ساده یا Edge Function دوره‌ای).
- آپلود مستقیم تصویر/ویدئو از پنل به Supabase Storage (فعلاً لینک مستقیم URL وارد می‌شود؛ ساده‌ترین راه رایگان).
- تایید و تست دقیق API واقعی روبیکا برای ارسال پیام (توضیح در بخش ۴ بالا).
- انیمیشن‌های ورود/اسکرول با جزئیات بیشتر در صورت نیاز.
- مدیریت گرافیکی کاربران (لیست/جستجو) در پنل ادمین.

هیچ بخش «قلک طلا»، «کیف پول طلایی» یا موجودی طلا در پروژه وجود ندارد.
